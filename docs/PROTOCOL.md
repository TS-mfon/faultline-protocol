# Faultline v1 implementation contract
Fresh project: no reuse or inspection of other local repositories. Public protocol types are defined in packages/protocol/src/index.ts. All amounts are decimal strings of USDC micro-units. All hashes/IDs are lowercase 0x-prefixed 32-byte SHA256; addresses normalized lowercase. RFC8785 canonical JSON is the commitment format. GenLayer Python must reproduce these canonical bytes (integer-only manifest fields, lexically sorted keys, no ASCII escaping, compact separators); hash raw fetched bytes before parsing snapshots.

## Fixed behavior
Up to 8 mandate nodes / 16 DAG edges. 64KiB complete adjudication packet. Actor identities are EOAs. Agent bonds each cover at least the complete repairCap. Policy weights primary=3, contributory=1, others=0. Sum node weights per agent, distribute integer price proportionally; remainder micro-units to liable addresses in ascending address order. One finding per node in the disputed dependency path; unrelated nodes remain unclassified. Never pay a liable repairer. One case and one repair cycle per run; case has at most two evidence rounds. Response 24h (all participants may close early), cure 24h, repair48h, hard lock7days. Native chain appeal windows are never shortened by application timers.

Activation requires every participant's GenLayer acceptance and Base funding receipt to match workflow hash. Every handoff binds exact latest predecessor handoffs and artifacts; consumers acknowledge before producing. Immutable terms after acceptance. Evidence snapshots include full relevant text, commitments, handoffs, signed chain receipt references, and failure report. No injection label/expected answer enters judge evidence.

GenLayer decides outcome DECIDED|NEEDS_EVIDENCE|UNRESOLVED, findings, causal edges and remedyId. JSON fields in DecisionSchema are authoritative. Compare independently obtained substantive fields; verify evidence citations and duties. Malformed output or independent mismatch must disagree, not become exoneration. No award if material unresolved findings. Protocol Undetermined/errors are not contractual UNRESOLVED. Repair verification is a separate successful finalized judgment.

## Infrastructure and trust
Vercel Next.js routes; MongoDB Atlas+GridFS immutable hash endpoints; GitHub Actions cron/dispatch worker (no Vercel Cron/Postgres). Durable jobs with atomic leases, idempotency keys, outbox. Signers and attestor separate from generated-code sandbox. A single attestor is trusted to verify chain truth; caps do not make this bridge trustless. Check finalized status AND successful execution AND deployment/hash/decision binding. Native finalization is explicit, never inferred from elapsed time. Reserve and release only after respective finality. Late signatures lose to Base expiry. Fee metering only; no protocol fees.

Settlement implementation: releaseRepair creates credit. The service queues a separate payout/withdrawFor operation and records completed only after a finalized successful withdrawal with the matching USDC Transfer. Matured refunds and participant withdrawals remain separate durable cleanup jobs, including for terminal application cases.
