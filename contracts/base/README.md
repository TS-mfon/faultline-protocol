# Faultline Base escrow

Self-contained, nonupgradeable Solidity 0.8.30. Target: Base Sepolia (84532), canonical USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e` (6 decimals). Constructor: `(USDC, attestor, guardian)`. No deployment is claimed by this package.

The compiler-generated **ABI is an array** at `abi/FaultlineBondEscrow.json`. `abi/authorization-schema.json` supplies exact EIP-712 field names, order, types, phase codes and state codes. Import these files in the gateway/worker; do not hand-author calldata. `python3 contracts/base/publish.py --check` detects publication drift after a build.

## Gateway operations

- `createWorkflow(workflowId, workflowHash, agents, caps, repairCap, repairs, nodeIds, nodeAgents, genlayerChainId, genlayerContract)` is permissionless and may be sent by a nonparticipant orchestrator/worker. Agents must be unique EOAs sorted by numeric address ascending; caps correspond to that order. Every agent must own at least one of the 1–8 nodes and bond at least repairCap. Node IDs are unique; nodeAgents are zero-based indexes into agents. Remedies are `(id, recipient, price)`, 1–8 entries, unique IDs, positive prices <= repairCap. Every amount is an integer USDC micro-unit <= 10^24-1.
- Node/remedy IDs in the TS manifest are slugs: encode each as `sha256(UTF8(slug))`. Keep nodes in manifest order. workflowId and workflowHash are the protocol's SHA256 bytes32 values; workflowHash commits the full canonical manifest including DAG, duties and remedy scopes.
- `getWorkflow(id)` returns a named tuple: state, workflowHash, termsHash, GenLayer chain/contract, repairCap, deadlines, nextNonce, fundedCount, caseId, activation/repair/reservation judgment and snapshot commitments, repairHash, remedyId, reserved amount. Read its compiled tuple names directly.
- `getTerms(id)` returns agents, nodeIds, nodeAgents and repairs. `bondCap(id, agent)` returns each cap. There is no term-edit operation.
- Funding: participant approves USDC for its **exact full cap**, then sends `depositBond(id)` from its own address. `originalDeposit(id, agent)` and `BondDeposited(id, agent, amount)` establish funding. Confirm successful Base receipts, target contract/token and workflowHash before reporting funded. An intent or signature is not funding.
- `openCase(id, caseId)` is sent by a funded participant while Active. This permits one case, and no repairs can reserve until CaseOpen. A keeper may relay all attested authorization methods from any account.
- `getAccount(id, agent)` returns `(cap, deposited, credit, debit, withdrawable)`. credit is the locked ledger balance before maturity, debit is the per-agent reserved debit (historical after release, zeroed after refund), withdrawable accounts for lazy expiration. Separate primitive getters remain available.
- `withdraw(id)` pays the caller. `withdrawFor(id, beneficiary)` is permissionless and always transfers to that exact ledger beneficiary. Withdrawals can materialize expiration themselves.

## Worker authorizations and source trust

Use `signTypedData({domain, primaryType, types: {[primaryType]: schema.types[primaryType]}, message})`. Domain is `FaultlineBondEscrow`, version `1`, current Base chain ID, and actual escrow address. Solidity structs are flat/static. EIP-712 uses Keccak; protocol snapshot hashes remain SHA256. `hashActivation`, `hashReservation`, `hashRelease` return the final 0x1901 EIP-712 digest for signer parity checks. Signatures are exactly 65 bytes with low-s and v=27/28.

EVERY authorization binds workflowId/hash, exact stored termsHash, frozen GenLayer chain/contract, case/snapshot/decision IDs, phase, the current per-workflow nonce, and expiry. `termsHash = keccak256(abi.encode(all createWorkflow args in ABI order))`. The attestor must independently reconstruct and compare those terms to the accepted canonical manifest, not blindly sign the stored hash. This prevents a creator substituting a recipient, node owner, cap, or source while retaining the same workflowHash. Participants must likewise check terms/source before funding. The workflow ID is unique for the lifetime of the deployment. A third party can precreate an ID; funders must reject mismatched terms or insufficient remaining lock time, and use a new run ID if an incompatible record occupies it. Caller identity never substitutes for manifest/hash verification.

- **ActivationAuthorization / phase 1 / nonce 0**: caseId must be zero; snapshotHash commits the acceptance/funding proof snapshot; decisionId identifies the successful finalized GenLayer activation. All participants must have accepted precisely this workflowHash on the bound deployment AND deposited on Base. Snapshot and decision IDs must be nonzero. Activation never extends the deadline.
- **ReservationAuthorization / phase 2 / nonce 1**: caseId must equal the opened case. snapshotHash and decisionId identify the frozen responsibility snapshot and its successful finalized DECIDED judgment. remedyId selects the frozen action. `classesHash = keccak256(abi.encode(uint8[] classes))`; send the same classes as the second reserveAward argument. One entry per frozen node, 0 for absent, 1/2/3/4 for the protocol class codes. Any unresolved (5), unknown code, all-zero liability, or liable repairer rejects the award. Sum 3:1 node weights by agent; floor proportional price then give leftover micro-units to liable agents in ascending address order. Reservation transfers no tokens.
- **ReleaseAuthorization / phase 3 / nonce 2**: caseId/remedyId match reservation; reservationDecisionId and reservationSnapshotHash explicitly bind that award. snapshotHash is the repair-verification snapshot, repairHash commits the repair submission, and decisionId is a NEW, successful finalized GenLayer repair judgment accepting that repair. Release creates a fixed recipient credit; it does not call the token. The residual bonds and recipient credit become immediately withdrawable.

Reservation and release types assert different successful judgments. The attestor must never sign for NEEDS_EVIDENCE, UNRESOLVED, malformed/mismatched independent findings, protocol Undetermined, failed execution, unfinalized native appeals or unsuccessful repair. **Base cannot independently verify GenLayer consensus**: this is a disclosed single-attestor bridge. Validate successful execution AND explicit native finality AND source deployment/hash bindings. Check all authoritative DecisionSchema fields, including evidence/duty scope, substantive independent agreement and remedy. Response/early-close, cure and native appeal windows are enforced on GenLayer and checked by the attestor, not inferred by Base timers. No application timer can certify finality.

The hard lock is seven days from **Base creation**, including unfunded/partially funded workflows. Coordinate creation/activation so the accepted lifecycle fits that immutable limit. Repair has at most 48 hours from Base reservation, capped by the original hard deadline. All deadlines are exclusive; late signatures lose even if nobody called refundExpired. expiry must be <= hardDeadline. A release can carry a later signature expiry than repairDeadline, but cannot execute at/after repairDeadline.

Failed/unresolved/no-award cases expire at the hard deadline. Reserved but failed/unfinalized repairs expire at the repair deadline. `refundExpired` restores each exact recorded debit and is idempotent. Only actual deposits become refundable; an unfunded cap never creates credit. Expired withdrawals never consume another participant's credit. Guardian pause blocks creation, funding, activation, case opening, reservation and release; it **cannot block refunds or any matured withdrawal**, including credits matured before pause.

Events: `WorkflowCreated`, `BondDeposited`, `WorkflowActivated`, `CaseOpened`, `AwardReserved`, `RepairReleased`, `WorkflowExpired`, `Withdrawn`, `PauseChanged`. Match indexed workflow/case/remedy/decision fields using ABI and read getWorkflow for full source and hash binding. An emitted reservation is not payment; a release is credit; only successful Withdrawn plus token receipt/balance evidence establishes token delivery.

## Verification

Run `bash contracts/base/verify.sh` or the driver's `node scripts/verify.mjs escrow`. No forge-std, package installs, network, RPC, or root config edits are needed. Cached native solc 0.8.30 and Foundry are prerequisites. `forge build --root contracts/base --offline` then `python3 contracts/base/publish.py` refreshes publications after intentional ABI changes.

The token adapter accepts standard bool-return and no-return transfers, rejects false/malformed/reverting calls, and verifies exact sender and recipient balance deltas. Reentrancy protects all mutations. Fee/rebasing tokens are unsupported; USDC issuer freezes/blacklisting can still prevent token delivery, with credit retained when a transfer reverts. Unsolicited token donations create no claims and there is no administrative sweep. Contract-based/1271 attestors are unsupported.
